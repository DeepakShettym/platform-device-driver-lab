
# Platform Device Driver Lab

This repository contains sample implementations and experiments using the Linux platform bus, platform devices, and platform drivers. It includes hands-on code examples for:

- Defining and registering platform devices
- Creating and binding platform drivers
- Passing custom platform data
- Interacting with device tree and non-device tree setups
- Exploring module init/exit, probe/remove functions, and data exchange

The examples are organized to help understand how the Linux driver model works with platform-specific hardware interfaces.
